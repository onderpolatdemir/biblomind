# 🚀 BiblioMind Backend - Hızlı Başlangıç

## Server Nasıl Çalıştırılır?

### 🪟 Windows (PowerShell)

```powershell
cd C:\Users\kaany\Desktop\bitirme\biblomind\backend
.\scripts\start_server.ps1
```

```bash
cd ~/Desktop/bitirme/biblomind/backend
```
