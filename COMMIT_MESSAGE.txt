## 🎯 Teknik Detaylar

### Algorithms
- **User Preference Vector:** Weighted average of book embeddings
  - purchase: 1.0, like: 0.8, cart: 0.6, view: 0.3
- **Content Similarity:** pgvector cosine distance (<=>)
- **Hybrid Scoring:** content*0.7 + popularity*0.2 + recency*0.1

### Database
- PostgreSQL pgvector extension for vector operations
- 1536-dimensional embeddings (text-embedding-3-large)
- User preference vectors stored in users.preferences_vector
- Book embeddings in books.embedding

### Performance Optimizations
- pgvector native operators (80ms vector query)
- Query LIMIT optimization (30 instead of 100)
- Background task architecture (async updates)
- Disabled explanation generation in tests
